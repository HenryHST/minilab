# ADR-0028: n8n (Community, ForwardAuth)

- **Status:** Superseded (removed from Dev)
- **Datum:** 2026-09-29
- **Entfernt:** 2026-10-28
- **Kontext:** früher `apps/dev/n8n/`, Issue [HenryHST/minilab#87](https://github.com/HenryHST/minilab/issues/87)

## Kontext

Workflow-Automatisierung sollte auf nXk3 laufen (LAN-only). Native n8n-OIDC (`N8N_SSO_*`) ist Enterprise-only — Community-Edition nutzte Traefik ForwardAuth.

## Entscheidung (historisch)

- ApplicationSet `dev`, Wave 3, Pfad `apps/dev/n8n`; 8gears Helm → `helm-manifest.yaml`.
- Host `n8n.stadthagen.dev`, ForwardAuth Outpost `ak-outpost-n8n` (Day-0 `day0-n8n`).
- Postgres hostPath auf `nxk3-w01`; NFS-Backup 03:30 UTC.

## Superseded

n8n wurde aus der Minilab-Dev-Umgebung entfernt (App, Day-0 Blueprint, Homepage/Gatus, BookStack-Buch). Lab-Verdrahtung in Infra_LAB (SecretSpec / Authentik-Gruppen / UniFi DNS) wird parallel bereinigt.
