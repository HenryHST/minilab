# Willkommen: Erste Schritte am Homelab

## Was Sie erreichen

Sie kennen die wichtigsten Homelab-Seiten und können sich mit Ihrem Konto anmelden.

## Was Sie brauchen

- Computer oder Smartphone mit Browser
- Homelab-Benutzerkonto (Authentik) — falls noch keines existiert, Admin fragen

## Schritte

1. Öffnen Sie die Startseite: **https://web.stadthagen.dev**
2. Klicken Sie auf den gewünschten Dienst (z. B. Passwörter, Status, Wiki).
3. Wenn eine Login-Seite erscheint, melden Sie sich mit Ihrem **Homelab-Konto** an.
4. Nach dem Login sollten Sie die Anwendung sehen.

## Wenn etwas nicht klappt

| Problem | Hilfe |
|---------|-------|
| Seite nicht erreichbar | WLAN/VPN prüfen; später Status-Seite oder Admin |
| Login schlägt fehl | Passwort zurücksetzen lassen / Admin |
| „Keine Berechtigung“ | Admin um Freischaltung bitten |
