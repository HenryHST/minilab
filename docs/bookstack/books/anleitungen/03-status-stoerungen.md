# Status & Störungen

## Was Sie erreichen

Sie prüfen, ob Homelab-Dienste online sind, bevor Sie ein Problem melden.

## Was Sie brauchen

- Browser
- Optional: Homelab-Login (manche Status-Seiten sind ohne Login sichtbar)

## Schritte

1. Öffnen Sie **https://status.stadthagen.dev**
2. Prüfen Sie die Übersicht: grün = erreichbar, rot/orange = Störung.
3. Notieren Sie **welcher Dienst** betroffen ist und **seit wann** (Uhrzeit).
4. Wenn der Dienst laut Status online ist, aber bei Ihnen nicht funktioniert: Gerät, Browser und WLAN prüfen, dann Admin informieren.
5. Bei größerer Störung: warten auf Hinweis vom Admin; unnötige „Reparaturversuche“ vermeiden.

## Tipps

- Screenshot der Status-Seite hilft bei der Fehlersuche.
- Wiki mit Anleitungen: https://book.stadthagen.dev

## Wenn etwas nicht klappt

| Problem | Hilfe |
|---------|-------|
| Status-Seite selbst offline | Anderes Netz versuchen; Admin informieren |
| Ein Dienst rot | Betroffene URL nennen, nicht alle Dienste neu starten |
