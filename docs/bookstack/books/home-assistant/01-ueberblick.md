# Home Assistant — Überblick

## Was Sie erreichen

Sie wissen, wofür Home Assistant da ist und wie Sie die Oberfläche öffnen.

## Was ist Home Assistant?

Home Assistant steuert und zeigt den Status von Geräten zu Hause — z. B. Lichter, Heizung, Sensoren oder Steckdosen. Alles läuft über eine Webseite oder die Handy-App.

Sie müssen **nichts installieren oder programmieren**, um Alltagsfunktionen zu nutzen. Fertige Dashboards und Automationen werden vom Admin gepflegt.

## Was Sie brauchen

- Computer, Tablet oder Smartphone mit Browser
- Homelab-Konto (falls Login über Authentik) **oder** den von Admin genannten Benutzer
- Ideal: gleiche WLAN-/VPN-Verbindung wie zu Hause bzw. freigegebener Fernzugriff

## Schnellstart

1. Öffnen Sie **https://ha02.stadthagen.dev**
2. Melden Sie sich an (siehe Kapitel *Anmelden & App*)
3. Sie sehen die **Übersicht** (Dashboard) mit Räumen und Geräten
