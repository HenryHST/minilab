# Die Übersicht lesen

## Was Sie erreichen

Sie verstehen die Startseite (Dashboard) und finden Räume sowie Gerätezustände.

## Was Sie brauchen

- Angemeldet unter **https://ha02.stadthagen.dev** (oder in der App)

## Die Startseite

Nach dem Login sehen Sie meist eine **Übersicht** mit Karten:

- **Räume** (Wohnzimmer, Küche, …)
- **Geräte** (Lampen, Thermostate, Steckdosen, Sensoren)
- Manchmal **Wetter**, Personen oder Energie

Jede Karte zeigt den aktuellen Zustand — z. B. an/aus, Temperatur, geöffnet/geschlossen.

## Navigation

1. **Menü** (oben links) öffnen
2. **Übersicht** = Haupt-Dashboard
3. Weitere Dashboards erscheinen im Menü, falls der Admin welche angelegt hat (z. B. „Erdgeschoss“, „Garten“)
4. Mit dem **Pfeil zurück** oder erneut „Übersicht“ zur Startseite

## Status verstehen (typisch)

| Anzeige | Bedeutung (häufig) |
|---------|-------------------|
| Gelb / hell / „an“ | Gerät eingeschaltet |
| Grau / dunkel / „aus“ | Gerät ausgeschaltet |
| Temperatur in °C | Ist-Wert (Sensor oder Heizung) |
| Schloss / Tür-Symbol | Offen oder geschlossen |
| Rotes Ausrufezeichen | Gerät oder Integration gestört — Admin informieren |

> Die genauen Farben und Namen hängen von Ihrer Installation ab. Im Zweifel den Namen auf der Karte lesen.

## Nur ansehen vs. steuern

- Viele Karten sind **zum Tippen** (schalten)
- Manche sind **nur Anzeige** (z. B. Außentemperatur) — Tippen ändert nichts oder öffnet nur Details
- Detailansicht: auf die Karte tippen → Verlauf, mehr Infos, ggf. Schieberegler

## Wenn etwas nicht klappt

| Symptom | Was tun |
|---------|---------|
| Übersicht leer | Anderes Dashboard im Menü wählen; Admin fragen |
| Alles „nicht verfügbar“ | Gerät/Bridge offline — Status-Seite; Admin |
| Falsche Sprache | Profil → Sprache (falls freigegeben) oder Admin |
