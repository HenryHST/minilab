# Lichter & Schalter

## Was Sie erreichen

Sie schalten Lampen und Steckdosen ein und aus und stellen die Helligkeit ein (falls unterstützt).

## Was Sie brauchen

- Angemeldet in Home Assistant
- Licht oder Schalter, das auf dem Dashboard sichtbar ist

## Licht ein- / ausschalten

1. Öffnen Sie die **Übersicht** (oder das Raum-Dashboard)
2. Finden Sie die gewünschte Lampe (Name z. B. „Wohnzimmer Decke“)
3. Tippen Sie auf die Karte bzw. den Schalter
4. Das Licht wechselt zwischen **an** und **aus**
5. Fertig — der Zustand auf der Karte sollte sich sofort ändern

## Dimmen / Farbe (falls vorhanden)

1. Tippen Sie **kurz** auf die Lampen-Karte, um Details zu öffnen
2. Schieberegler für **Helligkeit** bewegen
3. Falls vorhanden: Farbe oder Weißton einstellen
4. Dialog schließen — die Einstellung bleibt aktiv

## Steckdosen / Schalter

Gleiche Bedienung wie bei Lichtern:

1. Karte der Steckdose finden
2. Tippen = an/aus
3. Nur Geräte schalten, die Sie kennen (z. B. keine „Server“- oder „NAS“-Steckdosen ohne Absprache)

## Mehrere Lichter (Gruppe)

Manchmal gibt es eine Karte „Alle Lichter Wohnzimmer“:

1. Diese Gruppen-Karte tippen
2. Alle zugehörigen Lichter schalten gemeinsam

## Wenn etwas nicht klappt

| Symptom | Was tun |
|---------|---------|
| Tippen ändert nichts | Warten 2–3 Sekunden; Seite neu laden |
| Gerät „nicht verfügbar“ | Strom/Gerät prüfen; Admin (Zigbee/WLAN) |
| Falsches Licht geht an | Namen vergleichen; Admin um Umbenennung bitten |
| Nur in der App kaputt | Im Browser testen — wenn dort ok, App neu starten |
