# Szenen & Automationen

## Was Sie erreichen

Sie starten fertige Abläufe (Szenen) und verstehen, was Automationen automatisch tun — ohne selbst zu programmieren.

## Was Sie brauchen

- Angemeldet in Home Assistant
- Auf dem Dashboard sichtbare Szenen-Buttons (falls eingerichtet)

## Was ist was?

| Begriff | Einfach erklärt |
|---------|-----------------|
| **Szene** | Ein Tastendruck stellt mehrere Dinge gleichzeitig ein (z. B. „Filmabend“: Licht dimmen, Rollos zu) |
| **Automation** | Läuft **von allein** nach Regel (z. B. bei Sonnenuntergang Licht an) |

Sie **starten** Szenen; Automationen laufen im Hintergrund. Neue Automationen legt der Admin an.

## Szene starten

1. Übersicht öffnen
2. Bereich **Szenen** / Buttons mit Namen wie „Gäste“, „Nacht“, „Abwesend“ suchen
3. Auf die gewünschte Szene tippen
4. Geräte stellen sich um — kurz warten und prüfen

## Typische Szenen (Beispiele)

Namen bei Ihnen können abweichen:

| Szene (Beispiel) | Typische Wirkung |
|------------------|------------------|
| Anwesend / Zuhause | Komfort-Licht und Heizung |
| Abwesend | Licht aus, Absenkung |
| Nacht | Wege-Licht, Ruhe |
| Filmabend | Dimmen, ggf. Beamer/Steckdose |

## Automationen — was Sie wissen sollten

- Sie müssen nichts starten — Regeln laufen selbst
- Wenn etwas „von allein“ passiert, ist oft eine Automation schuld (gewollt)
- Automationen **nicht** in den Entwickler-Einstellungen ändern
- Stört eine Automation: Admin sagen (Name, Uhrzeit, was passiert ist)

## Wenn etwas nicht klappt

| Symptom | Was tun |
|---------|---------|
| Keine Szenen sichtbar | Noch nicht angelegt oder keine Rechte — Admin |
| Szene tippen ohne Wirkung | Geräte offline; Szene veraltet — Admin |
| Etwas schaltet sich unerwünscht | Uhrzeit + Gerät notieren → Admin (Automation prüfen) |
| „Ausgeführt“ aber nichts passiert | 10 Sekunden warten; betroffene Geräte einzeln prüfen |
