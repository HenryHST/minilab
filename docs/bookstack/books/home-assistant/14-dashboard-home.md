# Dashboard Home

> Stand: 2026-10-17 · Dashboard **`dashboard-home`** (Sidebar: **Home**)

## Was Sie erreichen

Sie kennen die Tabs des Dashboards **Home**, wissen wo Räume und Spezial-Ansichten liegen, und erkennen die wichtigsten Karten auf der Startseite.

## Was Sie brauchen

- Angemeldet unter **https://ha02.stadthagen.dev**
- In der linken Leiste den Eintrag **Home** (Haus-Symbol) — nicht zu verwechseln mit dem Dashboard **Start**

## Öffnen

1. Menü links öffnen
2. **Home** tippen
3. Oben bzw. in der Navigationsleiste erscheinen die **Tabs** (Home, Wohnzimmer, Küche, …)

Direkt-URL (Beispiel Start-Tab): `https://ha02.stadthagen.dev/dashboard-home/0`

## Tipps

- Anderes Dashboard (**Start**, **Finanzen**, **Karte**): eigenständige Einträge in der Sidebar — nicht Teil dieses Kapitels
- Raum bedienen: zuerst den Raum-Tab, dann die Karte tippen
- Gerätelisten (Zigbee / Homematic): Kapitel *Systemübersicht*

## Wenn etwas nicht klappt

| Symptom | Was tun |
|---------|---------|
| Tab fehlt | Anderes Gerät / andere Rechte — Admin |
| Screenshot / Karte leer | Neu laden; Integration offline — Status-Seite |
| Falsches Dashboard | Sidebar: Eintrag **Home** wählen |

## Hilfe

- Kapitel *Übersicht lesen*, *Lichter & Schalter*, *Systemübersicht*
- Ansprechpartner: Homelab-Admin
