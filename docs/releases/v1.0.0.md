# Release v1.0.0 — 2026-11-06

**Major:** nXk3 GitOps-Edge wechselt von Traefik auf **Cilium Gateway API**. Alle öffentlichen App-Routen laufen über `HTTPRoute` + TLS-`ReferenceGrant`; Auth am Edge über Authentik **ExternalAuth** (Envoy-Outpost). Zentraler Stack: `apps/infra/gateway` (Gateway `nxk3`, VIP **`192.168.0.215`**).

Begleit-Release Plattform: **[Infra_LAB v2.0.0](https://github.com/HenryHST/Infra_LAB/releases/tag/v2.0.0)** (Cilium Gateway enablement, Traefik aus, ADR-0028, BookStack Cilium 1.4.0).

## Highlights

- Hard-Cutover Traefik → Cilium Gateway (PRs **#179–#184**)
- `apps/infra/gateway` inkl. `MIGRATION.md` und ExternalAuth-Matrix
- Traefik-Reste entfernt (`traefik-manager`, IngressRoute-Templates, Middleware-RBAC)
- NetworkPolicy-Standard: **open-port** für Gateway-Edge (nicht mehr nur `kube-system`)
- Kontinuierlicher Smoke: CronJob `gateway-smoke` alle 15 min + L2-/Job-Fail-Alerts
- k8s-toolbox **1.0.2** full/slim; Vaultwarden SMTP/Helm; Monitoring/HA/unpoller-Härten

## Breaking Changes

| Thema | Vorher | Nachher |
|-------|--------|---------|
| Routing-CRDs | Traefik `IngressRoute` / Middleware | Gateway API `HTTPRoute` (+ `ReferenceGrant` für TLS) |
| Auth-Filter | ForwardAuth Middleware | `ExternalAuth` → `/outpost.goauthentik.io/auth/envoy` |
| NetworkPolicy Edge | oft Ingress nur aus `kube-system` | App-Port offen für Cilium Gateway / `reserved:ingress` |
| error-pages | Traefik Middleware / Catch-all | Middleware entfernt; branded Gateway-5xx = Infra_LAB Limit |
| `traefik-manager` | Ops-App | entfernt |

Migration: [ADR-0038](../adr/0038-cilium-gateway-api.md), [`apps/infra/gateway/MIGRATION.md`](../../apps/infra/gateway/MIGRATION.md), [`EXTERNALAUTH.md`](../../apps/infra/gateway/EXTERNALAUTH.md).

## Ops

```bash
# manueller Smoke (Infra_LAB script oder Cluster-Job)
kubectl -n gateway-system create job smoke-manual --from=cronjob/gateway-smoke
kubectl -n gateway-system logs job/smoke-manual -c smoke --tail=40

# Edge-Sanity
kubectl -n gateway-system get gateway,svc
kubectl get httproute -A | head
kubectl get middleware,ingressroute -A   # erwartet: leer
```

Alerts: `GatewaySmokeJobFailed`, `GatewaySmokeStale`, `GatewayL2LeaseOnForbiddenNode` in `apps/monitoring/kube-prometheus-stack/manifests/homelab-alerts.yaml`.
